## TL;DR on the brand

- **Wabi-Sabi Entebbe** — *"A Japanese Fusion Restaurant"* + sushi bar, inside Hemingways Hotel,
  Mugwanya Rd, overlooking Lake Victoria; minutes from the airport. New (online since June 2026).
- **Identity:** a golden **ensō** crossed by sumi brushstrokes; **washi ivory + sumi ink + antique
  brass**; built on the *wabi-sabi* philosophy — beauty in imperfection, calm, the handmade.

## Honesty about coverage

This v1 is **grounded, not padded**. The website (Squarespace) is **password-locked** and both
social feeds are **walled to automated access**, so the **menu, prices, hours, brand story, and
real social content are not yet captured**. Everything here is sourced or clearly labelled as
inference. See [`knowledge-base/00-overview.md` §5–6](knowledge-base/00-overview.md) for the gap
list and how to fill it.

## To take this to v2

1. **Unlock the website** (Squarespace password) → real menu, story, hours, on-site design.
2. **Capture socials** via a logged-in Claude-in-Chrome pass → bio, posts, voice, feed visuals.
3. **Get brand assets** → vector logo, real fonts, menu PDF, photography.

Then re-run synthesis and re-sample colours from the live site to finalise the design system.
